🎶 Artist Music Website
Welcome to the official GitHub repository for the Artist Music Website! This project is a fully functional, responsive website designed to showcase an artist's music, Music Videos, Social media Accounts, and Contact in a visually captivating and user-friendly format.

🌟 Features
Home Page: A stunning introduction to the artist with their latest music releases and upcoming events.
Music Videos: Stream the latest tracks Music Videos.
Music Albums: Listen Latest track on Music App Accounts.
Gallery: A curated collection of photos and videos from concerts, photo shoots, and behind-the-scenes moments.
Contact Form: Use this form to contact the artist for collaborations , fan messages.

🛠️ Technologies Used
Frontend: HTML, CSS, JavaScript, SCSS (for responsive design using mixins),React
Animations:React-Framer Motion for smooth and dynamic visual effects
Frameworks: React for a seamless single-page application experience
APIs/Embeds: YouTube API for embedded video streaming
Deploy: Netlify
